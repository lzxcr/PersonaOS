## 背景

用户反馈三个问题 + 一个全局要求：
1. 接入平台（platforms）Enter 直接进全屏编辑，应改为「字段总览 → Enter 编辑」两层结构（同全局参数）
2. 编辑单个字段占全屏很古怪 → **内联编辑**：选中行直接变成输入框
3. 布尔/备选项切换 → **←/→ 左右键**（移除 Space）
4. 全项目一致性检查：TUI 各页面交互各自为政

## 设计（用户已确认）

### 统一层级模型
- **实体列表**（providers 供应商 / platforms 平台 / plugins 插件）→ Enter → **字段总览页**（该实体全部字段 `标签 = 值`）→ Enter → **内联编辑**该字段 → Esc 回列表
- **global** 直接是字段总览页（无实体列表层）

### 内联编辑
- 字段总览列表中，当前选中行渲染为 `标签 = {buffer}`（输入态样式：下划线/高亮）
- 其他行正常显示 `标签 = 值`
- 按键：Char/Backspace 输入；Enter 应用并跳到下一行（连续编辑）；↑↓/k/j 切换行并加载该行值；**←/→ 切换 bool/choices**（bool: 取反；choices: 循环前进/后退）；Esc 退出编辑
- 校验失败红字提示（global 机制推广到全部）

### 统一按键语义（全页面）
| 键 | 语义 |
|---|---|
| ←/→ | bool/choices 双向循环（**移除 Space**） |
| Enter | 应用并跳到下一字段（连续编辑） |
| ↑↓/k/j | 切换字段并重载当前值 |
| n | 编辑态=下一字段 |
| Esc | 退出编辑回总览 |
| 错误 | 总览页 hint 行红字 |

## 实施范围

1. `pages/mod.rs`：通用内联编辑渲染辅助 + 统一 hint 文案
2. `global`：全屏表单 → 内联编辑
3. `platforms`：加字段总览层 + 内联编辑（platform_rows 生成总览行）
4. `providers`：加字段总览层 + 内联编辑
5. `plugins`：detail 表单 → 字段总览列表 + 内联编辑
6. 错误提示推广到 platforms/providers/plugins
7. 移除所有 Space 切换（plugins 列表 Space 切插件开关保留——那是列表操作非字段编辑）
